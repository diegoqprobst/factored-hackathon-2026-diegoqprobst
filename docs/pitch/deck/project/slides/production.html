Running today, and what it would take to make it real

Running now

  • Live container on Render; bank data from a private dataset, startup fails closed
  • Every turn traced: route, LLM tokens and cost, tool calls, policy rule
  • Bounded retries; rules fallback when the LLM fails or hits its daily $0.50 cap
  • OTP with rate limit and lockout, signed sessions, idempotent writes
  • 350 tests; make pipeline, router and eval rebuild every number

Honest gaps → next step

  • Data is synthetic Spanish; PT is measured on our own labelled sets → real PT traffic
  • Eval reuses message templates → new phrasings from real contacts
  • The router often abstains in Portuguese → more labelled PT data, real traffic
  • One process, in-memory sessions, SQLite → Postgres, Redis, real SMS and IdP
  • Handoff is a JSON payload → an agent console and drift monitoring

Build something that works, prove it works, and know when not to act.
