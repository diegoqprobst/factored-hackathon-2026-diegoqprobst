The learned component is the router: intent, language and prompt-injection detection. There is no usable conversation text in the dataset, so we labelled 1,247 Spanish and Portuguese utterances, and the test set was written by hand and sealed in git before anything else existed. Splits are grouped so paraphrases of the same seed never cross, and we removed near-duplicates. The selection rule was fixed in advance. On the test set, both learned routers beat the keyword baseline by more than 20 points of macro-F1. The embedding model won by the rule, but we deploy TF-IDF because it fits the free tier, and we checked that end to end it matches.
