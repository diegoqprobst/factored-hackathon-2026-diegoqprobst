How do we know it works? 230 scripted conversations in Spanish and Portuguese, built from real sandbox records, sealed in git, and run through both systems. Scoring is deterministic: it reads what the agent wrote to the bank and what it handed off, not what it said. The hybrid safely resolved all 104 in-scope disputes against 86.5 percent for rules, made every required handoff, and the gap is biggest in Portuguese. It includes adversarial cases: prompt injection, expired sessions, another customer's charge, and tool failures. It had no unsafe outcome. We also show how we got here: version 2 had six unsafe filings, our first fix made things worse and we kept that run in the report, version 4 asked the customer when the router and the model disagree and left one unsafe case, and version 5 also asks when the keyword rules and the model read different reasons. It was then scored once on a new set of records sealed before the run.
